# MyNote

## Deskripsi

Project ini dibuat sebagai salah satu tugas mata kuliah **Pemrograman Mobile** menggunakan Kotlin. Aplikasi digunakan untuk membuat, mengubah, menghapus, dan mengelola catatan dengan tampilan Material 3.

---

## Fitur

- Tambah catatan
- Edit catatan
- Hapus catatan
- Pin catatan
- Pencarian catatan

---

## Teknologi

- Kotlin
- Android Studio
- Material 3
- Jetpack Compose
- Room Database
